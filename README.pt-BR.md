# mime-sniff-core

Detecção de tipo de arquivo pelos bytes mágicos iniciais: regras exatas,
desconhecido retorna null. Zero dependências, Node >= 22.

Parte do laboratório open source da LOFRANO TECNOLOGIA. MIT.

```sh
npm test          # 5 testes, node:test, sem dependências
npm run demo
```

12 tipos; lê no máximo 64 bytes. MIT — veja `LICENSE`.
